# Greenwood-Accountants-Microsoft-365-Identity-(Christtech.co.uk) Project

## Overview
This repository documents the Microsoft 365 Identity Foundation
build for Greenwood Accountants (christtech.co.uk).

The project implements:
- User provisioning and UPN naming convention
- Security group structure
- Multi-Factor Authentication via Conditional Access
- Self-Service Password Reset
- Password Protection
- Least-privilege admin role assignments

## Domain
Tenant: christtech.co.uk
Admin Centre: https://entra.microsoft.com
