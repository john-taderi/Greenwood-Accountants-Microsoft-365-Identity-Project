## Overview
This project focuses on configuring and testing Self-Service Password Reset (SSPR) in Microsoft 365 Tenant for Greenwood. The goal is to enable users to securely reset their passwords without administrator intervention while enforcing strong identity verification through multiple authentication methods.

The implementation includes:
- Configuring SSPR for users
- Requiring two authentication methods
- Testing the end-user password reset experience
- Comparing administrator configuration view with actual user experience
- Documenting findings and recommendations
