# Admin Role Assignment

### Role Assignment Purpose:
These roles were assigned to ensure proper delegation of responsibilities, improve operational efficiency, and enforce secure role-based access control within the Microsoft 365 environment.

### Assign Least Privilege Roles
| Role | Purpose |
|------|---------|
| User Administrator | Manage users, groups, licenses, and password resets |
| Exchange Administrator | Manage Exchange Online mailboxes, mail flow, and email settings |
| Teams Administrator | Manage Microsoft Teams settings, meetings, calling, policies, and collaboration features |
| Helpdesk Administrator | Reset passwords and support users |

### Role Assignment Process Approach I used
🚄Step 1: I Open Microsoft Entra Admin Center
Navigate to:
* Identity
* Roles & Administrators

🚄Step 2: Select Administrative Role
I choose the required role from the list of available administrator roles for each user.
- User Administrator
- Exchange Administrator
- Team Administrator

🚅Step 3: Assign Role to User
* Open the selected role
* Click Add Assignments
* Select the appropriate user
* Save the assignment

Users were assigned only the minimum permissions required to perform their responsibilities.
