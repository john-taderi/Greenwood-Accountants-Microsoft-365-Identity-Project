## Overview
Administrative role assignments in Microsoft 365 allow organizations to delegate specific permissions and responsibilities to authorized users. Role-Based Access Control (RBAC) helps ensure that administrators only have access to the tools and resources required for their job responsibilities.

This project focuses on assigning appropriate administrative roles within the Greenwood Accountants Microsoft 365 environment to support secure and efficient management.

## Objectives

The objectives of admin role assignments are to:
- Delegate administrative responsibilities securely
- Limit excessive permissions
- Improve security through least privilege access
- Separate administrative duties
- Enhance accountability and management control
